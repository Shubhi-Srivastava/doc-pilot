# DocPilot

AI-powered internal document search using Retrieval-Augmented Generation (RAG) with OpenAI, LlamaIndex, and Qdrant.

## Features
- Ingest & index internal documents into a vector database
- Query using natural language
- Private, secure, and company-specific answers

## Tech Stack
- **OpenAI** — LLM & embeddings
- **LlamaIndex** — RAG orchestration
- **Qdrant** — Vector database

## Setup
1. Clone the repo
2. Create a virtual environment
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Add your environment variables in `.env`
